# MelonEngine
Just your average OpenGL demo utilizing GLFW, GLAD, etc.

Use WASD for movement with mouselook. Press M to get to the menu. Navigate menu with A/D and Enter to select different test scenes. Esc unfocuses the mouse cursor.

Currently has no pipeline, with everything rendered staight to the framebuffer. Lighting is mostly all in one "lit" shader, but there is also an emissive shader. Old school linear distance fog.
